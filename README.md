# Nexus Digital — High-Performance Digital Marketing Web App

Nexus Digital is a modern, full-stack digital marketing agency web application built with Next.js 16 (App Router & Turbopack), Tailwind CSS, Firebase Auth & Firestore, MongoDB, NVIDIA NIM AI, and Cashfree Payment Gateway.

---

## 🚀 Key Features

- **Omnichannel Service Showcase**: SEO, Meta/Google Ads, Full-Stack Web Development, Social Media, Content & Branding.
- **Cashfree Payment Gateway Integration**: Live production checkout supporting UPI (Google Pay, PhonePe, Paytm, QR), Credit/Debit Cards, and Net Banking.
- **Automated Webhooks & Billing**: Instant order status synchronization and automated PDF invoice generation.
- **Omni-Bot Assistant**: NVIDIA NIM AI powered interactive consultant tailored for businesses in Gorakhpur, Uttar Pradesh & India.
- **Admin Command Center**: Real-time management of orders, leads, submissions, and subscriber newsletters.

## 🛠️ Development & Deployment

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
